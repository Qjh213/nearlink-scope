# 星闪链路体检仪 · NearLink Scope

> 把"这条链路到底稳不稳"变成可复现的数字。

给星闪（NearLink / SparkLink）开发者用的一台"无线示波器"：在同一颗芯片、同一根天线上，
量化 SLE 与 BLE 的端到端时延分布、抖动、丢包与抗干扰保持率，让"星闪比蓝牙稳"这句话变成带误差棒的图表。

## 当前状态

**W1 · 环境跑通 + SDK 能力确认（进行中）** —— 固件 `firmware/linkscope` 已成型（`timing` / `loopback` / SLE 双板三种角色，主机侧单测通过），
《平台能力确认表》见 `docs/W1-平台能力确认.md`；下一步是实机跑数：时基、噪声底、双板 RTT。

## 硬件基线

- 2 × BearPi-Pico H3863（Hi3863，Wi-Fi 6 + BLE + SLE 三合一）
- 干扰源：手机热点 / 笔记本 WiFi（脚本化启停）

## 三条设计主线

1. **测 RTT，不测单向时延** —— 两块板晶振不同步，单向时延误差被时钟偏差淹没；RTT 只用发起端单一时钟。RTT 再拆成「上行 + 对端处理 + 回程」三段，定位瓶颈。
2. **同板 BLE 对照** —— 一颗芯片、一根天线，把同一套探针协议跑在 BLE 上，得到变量唯一的对照组。这是本项目最硬的差异化。
3. **先测噪声底** —— 用本地回环量出工具自身的调度抖动，报告里注明"仅对超过噪声底的差异下结论"。
