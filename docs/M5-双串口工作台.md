# M5 · LinkScope双串口实验工作台

## 目标

用一个程序同时管理COM3分析端与COM4证据端，替代M1–M4期间“LinkScope + QCOM”并行操作，减少串口
占用冲突和两端日志错配。

## 第一版能力

- 主分析端保留RTT/SLE monitor解析、完整签名准入、统计与四类导出；
- 辅助终端独立选择COM口和完整串口参数；
- 两端禁止选择同一COM口；
- 辅助端提供文本/HEX显示和发送、时间戳、CRLF、DTR/RTS、清空与保存；
- 一键按COM4→COM3顺序打开端口，一键停止；
- 联合导出两端原始证据与 `run.json`。

## 串口参数映射

| 界面 | pyserial |
|---|---|
| No Ctrl Flow | `xonxoff=False, rtscts=False` |
| SW Ctrl Flow | `xonxoff=True` |
| HW Ctrl Flow | `rtscts=True` |
| None/Odd/Even/Mark/Space | 对应PARITY常量 |
| 1/1.5/2 StopBits | 对应停止位值 |

4数据位保留QCOM兼容选项，但pyserial、CH340或Windows驱动可能拒绝。程序必须显示底层错误，不能标记为
打开成功。460800/921600同样只表示可请求的串口配置，不保证板端UART支持。

## M5标准操作

1. 主窗口COM3、辅助窗口COM4，均使用115200/8N1/无流控/DTR和RTS关闭；
2. 点击双串口开始；
3. 先复位COM4，再复位COM3；
4. COM3完整平台签名ready后才开始正式样本与计时；
5. 到时停止双串口；
6. 联合导出到对应cfg/run目录；
7. 离线复核COM3统计、COM4连接/业务计数与run.json配置。
