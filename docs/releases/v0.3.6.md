# NearLink LinkScope v0.3.6（M3）

首个面向普通 Windows 用户的 LinkScope 桌面分发版本。

## 功能

- 自动识别电脑上的串口并以下拉列表显示；
- 实时解析板端 RTT 样本，显示时间序列、直方图和 CDF；
- 统计 p50、p90、p99、p99.9、最大值、jitter、timeout、dup、ooo、bad 和 drop；
- 从首个有效样本开始计算采集时长，停止后保留结果；
- 支持打开历史日志和导出数据。

## 下载选择

- `NearLink-LinkScope-0.3.6-Setup.exe`：推荐普通用户使用的一键安装包；
- `NearLink-LinkScope-0.3.6-Portable.zip`：解压即用的免安装版；
- `SHA256SUMS.txt`：下载完整性校验值。

目标电脑不需要安装 Python，但使用 BearPi-Pico H3863 时仍需正确安装 CH340 串口驱动。
