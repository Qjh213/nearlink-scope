# 星闪（NearLink / SLE）协议问题集 · 通识版

> 面向“把协议本身学明白”，不绑定任何具体项目、代码或实测数据。
> 标记：**★** 概念级（读概述即可答）｜**★★** 规范级（需翻对应章节）｜**★★★** 深水（需读实现、算一遍或设计实验）。
> 每题后面的“过关判据”是**能做什么**，不是答案——能画出来、能算出数、能解释参数单位，才算答完。

---

## 一、体系与术语

- **Q1 ★** 星闪（NearLink）协议族包含哪些接入方式？各自面向什么场景、什么速率的业务？
  - 过关判据：能画一张“SLB / SLE / 其他”的定位图，并各举两个典型应用。
- **Q2 ★** SLE 与 BLE 在哪些概念上同构（连接、事件、属性），哪些是 SLE 独有或改动的？
  - 过关判据：列一张对照表，至少 8 个概念，标出“同名同义 / 同名不同义 / 仅一方有”。
- **Q3 ★★** 星闪的协议栈分几层？每层的输入输出是什么？哪一层负责重传，哪一层负责寻址？
  - 过关判据：画分层图并在每层标注“负责什么、不负责什么”。
- **Q4 ★★** 星闪标准由哪些文档/部分构成（接入层、基础服务层、测试规范等）？各自管什么？
  - 过关判据：能说出查某个具体问题（例如“连接参数单位”）该翻哪一部分。
- **Q5 ★★** 星闪与 UWB、WiFi、BLE 在“定位精度、时延、吞吐、功耗”四个维度上各处于什么位置？
  - 过关判据：画四维雷达图，每维给出数量级而非精确值。

## 二、物理层与射频

## 附 B：建议的学习顺序

1. **先建坐标系**（一、二）：知道 SLE 在哪、用什么频段、吞吐量级，避免后面把参数学成孤立数字。
2. **再学连接与时隙**（三、四）：这是 SLE 与 BLE 差异最集中、也最容易被“参数表”掩盖的部分。
3. **然后学数据语义**（五）：决定你以后测出来的 RTT/丢包到底在度量什么。
4. **最后补广播、服务、安全**（六、七、八）：按需深入，做产品时再细读。
5. **贯穿始终**（九、十、十一）：每学完一层，问自己“这一层出问题，我在外部能观察到什么”。
